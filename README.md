# E-Commerce Performance Analytics (IDR)

End-to-end e-commerce data analytics portfolio processing raw sales data in Python, loading cleaned tables into Google BigQuery, querying category profitability with SQL, and visualizing insights in Data Studio / Looker Studio.

## Live Dashboard
- **Interactive Dashboard:** [Buka E-Commerce Performance Dashboard (IDR)](https://datastudio.google.com/reporting/c8f2fd3d-d3f0-439c-8934-2ab9ea8d14a2/page/4FzDG)

## Project Structure
- `analysis.py` — Data exploration and cleaning script
- `bigquery_pipeline.py` — Loads cleaned datasets to BigQuery
- `sql/` — SQL queries for analytics and views

## Tech Stack
- **Python** (WSL2 Ubuntu)
- **Google BigQuery** & **SQL**
- **Data Studio / Looker Studio**
- **Git & GitHub**
